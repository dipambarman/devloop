# 🚀 About DevLoop

**DevLoop** is a modern developer collaboration platform designed to streamline project management, task tracking, documentation, and team collaboration.

Inspired by industry-leading products like **GitHub**, **Linear**, **Jira**, **Notion**, and **Discord**, DevLoop combines powerful project management with a beautiful developer-first experience.

Rather than being another CRUD application, DevLoop focuses on **clean architecture**, **modern UI**, and **production-ready Laravel engineering practices**.

# 📦 Installation

## Clone Repository

```bash
git clone https://github.com/dipambarman/devloop.git

cd devloop
```

---

## Install Dependencies

```bash
composer install

npm install
```

---

## Environment

```bash
cp .env.example .env

php artisan key:generate
```

Update your database credentials inside `.env`.

---

## Database

```bash
php artisan migrate --seed
```

---

## Start Development Server

Terminal 1

```bash
php artisan serve
```

Terminal 2

```bash
npm run dev
```

Visit

```
http://localhost:8000
```
